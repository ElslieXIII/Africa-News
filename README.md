# Africa News

A phone-first reader for African business, deal and tech news. It brings stories from news sites and email newsletters into one feed, with a short briefing for every article, folders for saving stories, and an Ideas board for turning stories into deal follow-ups.

This repository publishes the website with GitHub Pages: a page explaining what the app does and how to use it, and an interactive version of the app.

All outlets, companies, people and stories are fictional.
